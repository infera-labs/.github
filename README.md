# Infera organization profile

This repository contains the shared GitHub profile and organization-wide community files.

## Profile files

- [`profile/README.md`](profile/README.md) is displayed on the Infera organization’s Overview page.
- [`profile/assets/logo.png`](profile/assets/logo.png) is the logo used in that profile.

GitHub expects a public organization profile README at `.github/profile/README.md`. Keep both the repository name and the `profile` directory in place so GitHub continues to display the profile correctly.
